## 3. 用户 Settings(`/settings`,登录后;与管理后台严格分离)

- IA 对标"纵向卡片堆叠"(单页居中 max-w,每卡=标题+内容+就地保存/即时生效):
  1. **账户**:email(只读)+当前团队(只读+切换入口)+登出。
  2. **外观与语言**:主题三档(接 WEB-THEME)/语言 zh·en(接 i18n)——即时生效。
  3. **对话偏好**:缺省模型(候选经 /models)/缺省 agent(经 /agents)——存 localStorage UI 偏好,
     发首条时预填(会话级锁语义不变)。
  4. **订阅与余额**:余额摘要(billing summary 复用)+"查看流水/价格页"入口。
  5. **能力入口卡**:技能库/连接(MCP)/作品库三个跳转卡(rail 面板同源,不重复实现)。
- rail 底部用户区加"设置"入口;无密码卡/无 API key 卡(机制不存在,不造)。
